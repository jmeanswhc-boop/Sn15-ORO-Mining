Python SDK

The oro-sdk package on PyPI provides both a CLI (oro submit) and a Python API client for interacting with the ORO Backend.

Installation

# Core SDK (public API only)
pip install -U oro-sdk

# With Bittensor wallet support (required for submission)
pip install -U "oro-sdk[bittensor]"

Usage

The quick start guide covers CLI-based submission via oro submit. For programmatic usage, such as submitting agents from Python, checking status, querying the leaderboard, or building automation, see the full SDK reference.
